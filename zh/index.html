有问题？有答案。

安装前你可能想知道的几件事。

一定要配置 API Key 才能用吗？
不需要。注册后就有免费额度，每天签到还能再领，装完即可分析。只有额度用完、或想用自己的模型时，才需要打开「自定义 API」填 Key。
我的 API Key 会被上传吗？
自定义 Key 只保存在本地浏览器，不会同步到服务器。走官方额度时，图片会发送到 ImgPrompt 的分析服务；走自定义 API 时，请求直接发到你填的接口地址。
支持哪些生成平台？
中英文提示词都能直接用于 ChatGPT、Gemini 这类对话式生图模型，也能用于 Midjourney、Stable Diffusion、Flux、即梦、豆包、通义万相一类工具。JSON 结果适合结构化归档或接入自动化流程。
快捷键是什么？可以改吗？
默认是 Alt / Option + S。想换键位，打开 chrome://extensions/shortcuts 在扩展快捷键页面里改。
所有网站都能用吗？
能。只要 Chrome 允许扩展在该页面运行，面板就能打开，本地文件也可以直接拖进面板。Chrome 商店页面和新标签页是常见的例外。
