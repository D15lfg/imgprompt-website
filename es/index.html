Todo lo que necesitas saber antes de instalar.

¿Necesito una clave API para usarlo?
No. Los créditos gratis llegan al registrarte y el check-in diario suma más, así que el análisis funciona nada más instalar. Solo necesitas una clave cuando se acaban los créditos o cuando quieres usar tu propio modelo.
¿Se sube mi clave API a algún sitio?
Las claves personalizadas se quedan en tu navegador local y nunca se sincronizan con un servidor. Con los créditos oficiales, las imágenes van al servicio de análisis de ImgPrompt. Con una API personalizada, las peticiones van directamente al endpoint que configures.
¿Con qué generadores funciona?
Ambos prompts funcionan tal cual en ChatGPT, Gemini y otros modelos de imagen conversacionales, y en Midjourney, Stable Diffusion, Flux, 即梦, 豆包 y 通义万相. La salida JSON sirve para archivar de forma estructurada o para flujos automatizados.
¿Cuál es el atajo? ¿Puedo cambiarlo?
Por defecto es Alt / Option + S. Para cambiarlo, abre chrome://extensions/shortcuts y modifica el atajo ahí.
¿Funciona en cualquier web?
Sí. El panel se abre en cualquier página donde Chrome permita extensiones, y también acepta archivos locales arrastrados. Las páginas de la tienda de Chrome y la página de nueva pestaña son las excepciones habituales.
