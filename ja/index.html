インストール前に知っておきたいことをまとめました。

使うのに API キーは必要ですか？
いいえ。登録すると無料クレジットが付き、毎日のチェックインでも追加されるので、 インストール直後から解析できます。キーが必要になるのは、クレジットを使い切ったとき、 または自分のモデルを使いたいときだけです。
API キーはどこかに送信されますか？
独自のキーはブラウザ内に保存され、サーバーへ同期されません。公式クレジットを使う場合、 画像は ImgPrompt の解析サービスへ送られます。独自 API を使う場合は、 設定したエンドポイントへ直接送られます。
どの生成ツールで使えますか？
2 種類のプロンプトは、ChatGPT、Gemini などの対話型画像モデルでも、 Midjourney、Stable Diffusion、Flux、即梦、豆包、通义万相 でもそのまま使えます。 JSON 出力は構造化した保存や自動処理に向きます。
ショートカットは何ですか？変更できますか？
既定は Alt / Option + S です。 変更するには chrome://extensions/shortcuts を開き、 そこでショートカットを設定し直してください。
どのサイトでも動きますか？
はい。Chrome が拡張機能の実行を許可しているページなら、どこでもパネルが開きます。 ローカルファイルをそのままドロップしても解析できます。Chrome のストアページと 新しいタブページは、通常の例外です。
