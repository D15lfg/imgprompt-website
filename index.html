Questions? Answers.

Everything you need to know before you install.

Do I need an API key to use it?
No. Free credits arrive on sign-up and more come from daily check-in, so analysis works right after install. You only need a key when credits run out or when you want your own model.
Is my API key uploaded anywhere?
Custom keys stay in your local browser and never sync to a server. With official credits, images go to the ImgPrompt analysis service. With a custom API, requests go directly to the endpoint you configured.
Which generators does it work with?
Both prompts work as written in ChatGPT, Gemini and other chat-based image models, and in Midjourney, Stable Diffusion, Flux, 即梦, 豆包 and 通义万相. The JSON output fits structured archiving or automated pipelines.
What is the shortcut? Can I change it?
Default is Alt / Option + S. To rebind, open chrome://extensions/shortcuts and change the shortcut there.
Does it work on any website?
Yes. The panel opens on any page where Chrome lets extensions run, and it also accepts local files dropped straight into it. Chrome's own store pages and the new-tab page are the usual exceptions.
